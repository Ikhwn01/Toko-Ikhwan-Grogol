## 🇮🇩 Versi Bahasa Indonesia

### Judul Proyek:
**Pengembang Web Sistem Manajemen Toko & Peramalan Stok (Single Exponential Smoothing)**

### Poin Deskripsi Pekerjaan :
- Mengembangkan aplikasi web manajemen inventaris ritel dan kasir (POS) menggunakan **PHP Native** dan **MySQL**, dilengkapi dengan engine peramalan kebutuhan stok berbasis data historis penjualan.
- Mengimplementasikan algoritma **Single Exponential Smoothing (SES)** dengan parameter pemulusan $\alpha$ fleksibel (0.1–0.9) untuk meramalkan estimasi stok barang periode berikutnya secara presisi.
- Membangun modul evaluasi galat otomatis berbasis metrik matematika **MAD**, **MSE**, **MAPE**, dan **Akurasi %** guna mengukur keandalan nilai prediksi peramalan.
- Merancang dasbor analitik visual berbasis **Chart.js** yang menampilkan grafik tren penjualan harian (*curved line area chart*) dan komposisi penjualan produk (*doughnut chart*).
- Mengembangkan script seeder PHP berkinerja tinggi untuk menggenerasi 20 master produk dan 500 transaksi penjualan realistis dalam rentang waktu 70+ hari.
- Merestrukturisasi arsitektur direktori proyek menjadi modular (`config/`, `includes/`, `laporan/`, `proses/`) serta memfasilitasi ekspor laporan fisik siap cetak ber-kop surat resmi.

## 🇬🇧 Versi Bahasa Inggris (English Version)

### Project Title:
**Full-Stack Web Developer – Smart Retail Inventory & Demand Forecasting System**

### Bullet Points for Resume / CV:
- Built a web-based retail inventory and Point of Sale (POS) application using **PHP** and **MySQL**, featuring a time-series forecasting engine for automated stock replenishment planning.
- Implemented the **Single Exponential Smoothing (SES)** algorithm with dynamic alpha parameter tuning ($\alpha = 0.1 \dots 0.9$) to accurately predict next-period product demand from historical transaction data.
- Developed an automated mathematical error evaluation engine analyzing **MAD**, **MSE**, **MAPE**, and **Accuracy Rate (%)** to validate forecasting reliability.
- Designed an interactive analytics dashboard with **Chart.js** visual analytics, featuring daily sales trend area curves and product contribution doughnut charts.
- Engineered a high-performance PHP data seeder script generating 20 product datasets and 500 sales transactions across 70+ days for stress-testing and demonstration.
- Architected a clean, modular folder structure (`config/`, `includes/`, `laporan/`, `proses/`) and implemented print-ready official report export modules.
